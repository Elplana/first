platform designed to ingest player performance metrics and output objective,
machine learning-driven fair market valuations in Euros (€).

3. WHAT FOOTBALLIQ CURRENTLY DOES
================================================================================
1. User Landing (/): Displays an editorial monochrome homepage featuring Jude
   Bellingham in a 5-layer hero section with a headline, live player search bar,
   a 3-step valuation process breakdown, 4 sample player cards with instant
   "Evaluate" shortcuts, and links to methodology.
2. Player Search & Autocomplete: Typing any player's name (e.g. Bellingham,
   Saka, Gyökeres) in the hero search bar queries the client-side database
   (playersData.json) in real time, displaying up to 6 suggestions with league,
   position, and market valuation badge. Pressing Enter or clicking a player
   routes to /valuation?player=... with all 17 performance metrics prefilled.
3. Player Database Exploration (/players): Users can browse all 3,670 European
   player profiles across 8 top leagues. Users can filter by search term, league,
   and position; sort ascending or descending by Name, League, Position, Market
   Value, or Rating; and paginate 20 rows per page. Clicking "Evaluate" on any row
   pre-populates that player into the valuation engine.
4. Valuation Engine Configuration (/predict): Users can adjust 17 performance
   metrics across 4 logical categories. Users can also select sample presets (Saka,
   Gyökeres, Odegaard, Rice, Eze).
5. Inference Execution: Clicking "Calculate Market Valuation" validates bounds
   and sends an HTTP POST request to http://localhost:8000/api/v1/predict. The
   backend computes normalized per-90 metrics, transforms features via OneHotEncoder
   and StandardScaler, predicts log valuation via GradientBoostingRegressor,
   exponentiates via np.expm1, and returns the raw and formatted Euro market valuation.
6. Result Presentation: Upon API response, /predict replaces the form with
   PredictionResult, rendering a valuation hero banner, 6 supporting metric cards,
   and a benchmark comparison chart.

9. BACKEND ARCHITECTURE & ENDPOINT AUDIT
================================================================================
Framework: FastAPI 0.139.0 + Uvicorn 0.50.2 + Pydantic 2.13.4
Entry Point: app/main.py

Endpoints:
- GET /: Returns API status and docs pointer.
- GET /health: Returns healthy/degraded status, model_loaded boolean, and model path.
- POST /api/v1/predict: Accepts PlayerPredictionRequest, returns PlayerPredictionResponse.
- GET /docs & GET /redoc: Interactive API documentation.

Predictor Flow:
1. Pydantic validates input and computes 11 per-90 metrics via compute_per90_metrics().
2. MarketValuePredictor builds 28-feature DataFrame.
3. Scikit-Learn ColumnTransformer applies OneHotEncoder and StandardScaler.
4. GradientBoostingRegressor predicts log_market_value.
5. np.expm1 converts log target back to raw Euros.
6. Returns formatted Euro string and rounded numeric value.
